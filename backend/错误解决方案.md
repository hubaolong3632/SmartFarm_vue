# MyBatis-Plus 与 Spring Boot 3.2.0 兼容性问题解决方案

## 错误信息
```
java.lang.IllegalArgumentException: Invalid value type for attribute 'factoryBeanObjectType': java.lang.String
```

## 问题原因
这是 MyBatis-Plus 与 Spring Boot 3.2.0 的兼容性问题。Spring Boot 3.2.0 对 Bean 定义的处理方式有所改变，导致旧版本的 MyBatis-Plus 无法正常工作。

## 解决方案

### 方案1：升级 MyBatis-Plus 到最新版本（推荐）

我已经将 MyBatis-Plus 版本升级到 **3.5.10**。如果还是不行，请尝试以下步骤：

1. **清理 Maven 缓存并重新编译**：
   ```bash
   cd utio/springboot
   mvn clean
   mvn dependency:purge-local-repository -DmanualInclude="com.baomidou:mybatis-plus-boot-starter"
   mvn compile
   ```

2. **如果 3.5.10 还是不行，尝试使用最新版本**：
   
   修改 `pom.xml`，将版本改为：
   ```xml
   <dependency>
       <groupId>com.baomidou</groupId>
       <artifactId>mybatis-plus-boot-starter</artifactId>
       <version>3.5.11</version>
   </dependency>
   ```

### 方案2：降级 Spring Boot 版本（如果方案1不行）

如果 MyBatis-Plus 3.5.10/3.5.11 仍然无法解决问题，可以降级 Spring Boot 到 3.1.x：

修改 `pom.xml`：
```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>3.1.5</version>  <!-- 从 3.2.0 改为 3.1.5 -->
    <relativePath/>
</parent>
```

### 方案3：使用原生 MyBatis（最后手段）

如果以上方案都不行，可以考虑使用原生 MyBatis 替代 MyBatis-Plus：

1. 移除 MyBatis-Plus 依赖
2. 添加 MyBatis 依赖：
   ```xml
   <dependency>
       <groupId>org.mybatis.spring.boot</groupId>
       <artifactId>mybatis-spring-boot-starter</artifactId>
       <version>3.0.3</version>
   </dependency>
   ```

## 验证步骤

1. **清理项目**：
   ```bash
   cd utio/springboot
   mvn clean
   ```

2. **重新编译**：
   ```bash
   mvn compile
   ```

3. **启动应用**：
   ```bash
   mvn spring-boot:run
   ```

4. **验证启动成功**：
   - 查看控制台，应该看到 "Started GreenhouseApplication"
   - 访问 http://localhost:8080/api/recipes 应该返回 JSON 数据
