# Spring Boot 项目启动说明

## 已修复的问题

1. ✅ 删除了所有旧的 JPA Repository 文件
2. ✅ 升级 MyBatis-Plus 版本到 3.5.8（兼容 Spring Boot 3.2.0）
3. ✅ 简化了 MyBatis-Plus 配置
4. ✅ 修复了 pom.xml 中的标签错误

## 启动步骤

### 1. 确保数据库已创建

执行 `utio/schema.sql` 创建数据库表：

```bash
mysql -u root -p < utio/schema.sql
```

或者手动创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS greenhouse_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE greenhouse_db;
SOURCE utio/schema.sql;
```

### 2. 配置数据库连接

修改 `src/main/resources/application.yml` 中的数据库连接信息：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/greenhouse_db?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: 你的密码  # 修改这里
```

### 3. 安装依赖并启动

**方式1：使用 Maven 命令**

```bash
# 进入项目目录
cd utio/springboot

# 清理并编译
mvn clean compile

# 运行项目
mvn spring-boot:run
```

**方式2：使用 IDE**

1. 在 IDEA 或 Eclipse 中导入项目
2. 等待 Maven 自动下载依赖
3. 运行 `GreenhouseApplication.java` 的 main 方法

### 4. 验证启动

启动成功后，访问以下地址验证：

- 健康检查：http://localhost:8080/api
- 获取所有配方：http://localhost:8080/api/recipes
- 获取最新传感器数据：http://localhost:8080/api/sensor-data/latest

## 常见问题

### 问题1：端口被占用

如果 8080 端口被占用，修改 `application.yml`：

```yaml
server:
  port: 8081  # 修改为其他端口
```

### 问题2：数据库连接失败

检查：
1. MySQL 服务是否启动
2. 数据库名称是否正确（greenhouse_db）
3. 用户名密码是否正确
4. 数据库是否已创建

### 问题3：MyBatis-Plus 相关错误

如果遇到 `factoryBeanObjectType` 错误：
1. 确保 MyBatis-Plus 版本是 3.5.8 或更高
2. 清理 Maven 缓存：`mvn clean`
3. 重新下载依赖：`mvn dependency:resolve`

### 问题4：找不到 Mapper

确保：
1. `@MapperScan("com.greenhouse.mapper")` 在主启动类上
2. 所有 Mapper 接口都有 `@Mapper` 注解
3. Mapper 接口在 `com.greenhouse.mapper` 包下
