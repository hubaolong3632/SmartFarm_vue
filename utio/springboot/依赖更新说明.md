# 依赖更新说明

## 已更新的依赖

### 1. MyBatis-Plus
- **旧版本**: `mybatis-plus-boot-starter` 3.5.10
- **新版本**: `mybatis-plus-spring-boot3-starter` 3.5.7
- **说明**: 使用专门为 Spring Boot 3 设计的 starter，兼容性更好

### 2. MySQL 驱动
- **旧版本**: `mysql-connector-j` (Spring Boot 管理版本)
- **新版本**: `mysql-connector-java` 8.0.26
- **说明**: 使用指定版本的 MySQL 驱动

### 3. 数据库驱动类名
- **已更新**: `application.yml` 中的 `driver-class-name` 从 `com.mysql.cj.jdbc.Driver` 改为 `com.mysql.jdbc.Driver`
- **说明**: 与 `mysql-connector-java` 8.0.26 版本匹配

## 下一步操作

### 1. 重新加载 Maven 项目

**IDEA:**
- 右键点击 `pom.xml` → Maven → Reload Project

**Eclipse:**
- 右键点击项目 → Maven → Update Project

### 2. 清理并重新编译

**使用 IDE:**
- Build → Rebuild Project

**使用命令行:**
```bash
cd utio/springboot
mvn clean compile
```

### 3. 启动应用

**使用 IDE:**
- 运行 `GreenhouseApplication.java` 的 main 方法

**使用命令行:**
```bash
mvn spring-boot:run
```

## 预期结果

启动成功后，你应该看到：
```
Started GreenhouseApplication in X.XXX seconds
```

然后可以访问：
- http://localhost:8080/api/recipes
- http://localhost:8080/api/sensor-data/latest

## 如果遇到问题

1. **PaginationInnerInterceptor 找不到符号**
   - 确保使用 `mybatis-plus-spring-boot3-starter` 而不是 `mybatis-plus-boot-starter`
   - 清理 Maven 缓存并重新下载依赖

2. **数据库连接失败**
   - 检查 MySQL 服务是否启动
   - 检查 `application.yml` 中的数据库连接信息
   - 确保数据库 `greenhouse_db` 已创建

3. **其他编译错误**
   - 清理项目：`mvn clean`
   - 重新编译：`mvn compile`
   - 检查 Java 版本是否为 17
